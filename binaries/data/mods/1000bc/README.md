# 1000 B.C. — The Long Road to Empire

A standalone single-player campaign framework for 0 A.D.

## Campaign

1. **Ashes at Dawn** — survive the first raid and secure the settlement.
2. **The Broken Road** — reopen the mountain trade route.
3. **River of Spears** — establish a fortified river crossing.
4. **The Gathering Storm** — unite neighboring settlements against a coalition.
5. **The Last Gate** — defend the capital and break the coalition command.

The campaign uses normal 0 A.D. economy, construction, technology, diplomacy, combat, and AI systems.
